# Single Page Resume Website (HTML Only)

This project is a single-page resume website created strictly using **HTML5 only**.  
No CSS, JavaScript or external libraries have been used, as per the assignment
requirements.

The resume layout and section structure follow the provided reference image and
PDF while using proper semantic HTML elements.

---

## Objective

To design and implement a single-page resume webpage using only HTML and
appropriate semantic tags.

---

## Technologies Used

- HTML5 only

---

## Features

- Single-page resume layout
- Proper use of semantic HTML elements such as:
  - `<header>`
  - `<main>`
  - `<section>`
  - `<article>`
  - `<footer>`
  - `<address>`
- Organized content structure similar to the given reference layout
- Tabular representation for academic information
- Clean and readable markup
- Designed to fit on **one page when exported as PDF**

---

## Sections Included

The resume contains the following sections as required:

- Header with name and profile information
- Contact details
- About
- Skills
- Projects
- Education
